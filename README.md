# 🎬 Club Movie Screening Ticket Booking

A simple and interactive **club movie screening ticket booking website** that allows users to register for a movie screening, complete a **₹0 payment confirmation**, and **download their ticket** instantly.

🌐 **Live Website:**  
👉 https://cbwebsite-nu.vercel.app/

---

## ✨ Features

- 🎥 Movie screening registration form  
- 💳 **₹0 payment section** for confirmation  
- 🎟️ Automatic ticket generation  
- ⬇️ **Download ticket option** for users  
- ⚡ Fast and responsive user interface  
- 🚀 Deployed on **Vercel**

---

## 🛠️ Tech Stack

- **HTML** – Structure  
- **CSS** – Styling and layout  
- **JavaScript** – Logic, ticket generation & download  

---

## ⚙️ How It Works

1. User fills in the movie screening details  
2. User completes the **₹0 payment confirmation step**  
3. Ticket is generated dynamically using JavaScript  
4. User can **download the ticket** instantly  
5. No real payment gateway is involved  

---

## 💳 Payment Information

- This project includes a **₹0 payment flow**  
- No real transactions are processed  
- Designed purely for **event confirmation purposes**  

---

## 🚀 Deployment

The project is deployed using **Vercel**.

To deploy:
1. Push the project to a GitHub repository  
2. Import the project into Vercel  
3. Deploy with default settings  
4. Access the live site using the Vercel URL
